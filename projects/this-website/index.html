Features

✨

Intro & particle network

Loading screen, welcome message, a canvas particle network, a glowing cursor and parallax.

🎬

Shuffled video & music

Random background videos with cross-fades and a shuffled playlist. Broken links are skipped automatically.

🕰️

Bangkok clock

Live time in Bangkok, with the year in both the Buddhist Era and AD.

🇹🇭

English / ไทย

One-click language switch that remembers your choice.

📚

Side menu

My projects, my reading list with progress bars, and a shuffling quote board.

📱

Works on phones

Tested down to 320 px wide.

How it's organized

Pagesindex.html (intro + login), Home/, Company/, projects/<name>/
Stylesassets/css/: base.css is shared, plus one file per page
Scriptsassets/js/: media.js (video + music), reveal.js (scroll effects), one file per page
MediaPlaylist in assets/media.json, files hosted on Supabase Storage
New projectCopy projects/_template/ and fill it in
